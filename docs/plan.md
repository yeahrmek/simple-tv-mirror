## Что уже есть в upstream

Foreground service, автозапуск при загрузке (выключен по умолчанию), `PARTIAL_WAKE_LOCK`, `MulticastLock`, `FLAG_KEEP_SCREEN_ON`, экран логов в памяти. Слабые места: служба `START_NOT_STICKY`, mDNS регистрируется один раз и не повторяется, нет сторожа, логи не переживают перезапуск и недоступны без ADB.

## 0. Репозиторий и CI

- `applicationId = io.github.yeahrmek.simpletvmirror`, имя приложения «Повтор экрана».
- Workflow `ci.yml`: на push и PR — `testDebugUnitTest assembleDebug`, APK как артефакт.
- Workflow релиза по тегу `v*`: подписанный `assembleRelease` в GitHub Releases. Ключ — вне репозитория, копия в Actions secrets.

Готово, когда: APK из Releases стоит на ТВ через Яндекс Диалоги, мак видит ТВ в «Повторе экрана».

## 1. Диагностика

- Журнал событий в файл с ротацией (1 МБ × 3): старт и смерть службы, регистрация mDNS, смена сети, подключение и отключение сессии с причиной, ошибки декодера.
- HTTP на ТВ: `GET /logs` отдаёт журнал, `GET /status` — состояние. Порт 8080, только локальная сеть.
- Прогон: фильм 2–3 часа, затем журнал.

Тесты:
- ротация: при превышении размера пишется новый файл, старше третьего удаляются;
- формат строки: время, событие, поля;
- `/logs` отдаёт файлы по порядку, `/status` — текущее состояние.

Готово, когда: по журналу любого обрыва видно, кто его начал — мак, сеть или ТВ.

## 2. Стабильность

- Служба `START_STICKY`, при перезапуске системой сервер поднимается сам. Автозапуск при загрузке включён по умолчанию.
- mDNS: повторная регистрация при смене сети (`ConnectivityManager.NetworkCallback`), при ошибке регистрации — повтор с backoff, периодическое переобъявление.
- Сторож: раз в 30 с проверяет, что сервер слушает порт; если нет — перезапуск сервера.
- После обрыва сессии экран ожидания и готовность к новому подключению не дольше 2 с.
- Отдельный процесс для нативного сервера — только если журнал покажет падения в нативном коде.

Тесты:
- машина состояний сервера: остановлен → запущен → сессия → обрыв → запущен; перезапуск из любого состояния;
- backoff: задержки растут до потолка и сбрасываются после успеха;
- сторож: при недоступном порте вызывает перезапуск ровно один раз, при доступном — ничего;
- смена сети вызывает переобъявление, повторное событие для той же сети — нет.

Готово, когда: убийство процесса, выдёргивание кабеля на минуту и переподключение Wi-Fi мака не требуют действий на ТВ.

## 3. Простота

- Экран ожидания: имя ТВ крупно и инструкция «На маке: Пункт управления → Повтор экрана → <имя>».
- Имя по умолчанию «Телевизор». Настройки upstream уходят в отдельный раздел.

## Приёмка

- Фильм 3 часа без обрывов.
- ТВ появляется в «Повторе экрана» не позже чем через 30 с после включения ТВ или переподключения Wi-Fi мака.
- Сон мака, пробуждение и повторное подключение работают без действий на ТВ.
- Неделя обычного использования домохозяйкой без обращения к разработчику.
