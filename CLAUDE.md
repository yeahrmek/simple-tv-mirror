# simple-tv-mirror

Приёмник AirPlay для Яндекс ТВ Станции (YaOS X). Мак транслирует экран на телевизор встроенным «Повтором экрана», на маке ничего не ставим. Сценарий один: смотреть сериалы и видео из браузера мака. Задержка не важна, важны простое подключение и стабильность: трансляция не рвётся, ТВ всегда виден в списке.

Форк [jqssun/android-airplay-server](https://github.com/jqssun/android-airplay-server) (GPLv3). Протокол AirPlay реализует UxPlay (C, через JNI), свой приёмник не пишем.

## Устройство

- Яндекс ТВ Станция на YaOS X, подключена по Ethernet через экстендер Keenetic. Мак по Wi-Fi, та же подсеть 192.168.1.0/24.
- ADB недоступен: режим разработчика в YaOS X закрыт. Логи и диагностику отдаёт само приложение по сети.
- APK ставится через Яндекс Диалоги (quick-apps) или с флешки. Приложения с правом ставить другие APK YaOS не пускает, поэтому самообновления нет.
- Мак иногда перестаёт видеть mDNS по Wi-Fi, лечится переподключением Wi-Fi. Со стороны ТВ это не исправить, только повторными объявлениями.
- Мак может засыпать, когда видео не играет. Обрыв при сне мака — нормальный сценарий: ТВ возвращается на экран ожидания.

## Правила работы с форком

- Меньше расхождений с upstream, чтобы подтягивать исправления UxPlay и декодеров. Пакет `io.github.jqssun.airplay` не переименовываем, меняем только `applicationId`.
- Наш код — отдельные классы с чистой логикой (без Android API) плюс тонкая обвязка в существующих классах. Функции upstream не удаляем, а выключаем значениями по умолчанию в `Prefs`.
- Upstream — remote `upstream`. Подтягиваем через merge в отдельной ветке.

## TDD

- Сначала тест, потом код. Логику (машина состояний, повторы с backoff, сторож, разбор настроек) держим в классах без Android API и тестируем JUnit на JVM (`./gradlew testDebugUnitTest`). Время и планировщик передаём параметрами, в тестах — `kotlinx-coroutines-test`.
- Обвязку с Android API (служба, NsdManager, ConnectivityManager) тестируем Robolectric, только если без этого нельзя проверить поведение.
- UxPlay и декодеры не тестируем, их проверяет прогон на ТВ (см. «Приёмка» в [docs/plan.md](docs/plan.md)).
- Тесты удаляются вместе с кодом, который они проверяют.

## Сборка

- JDK 21 (`/opt/homebrew/opt/openjdk@21`), Android SDK `~/Library/Android/sdk`, NDK ставит Gradle.
- Подмодули: `git submodule update --init --recursive`. Патчи к UxPlay применяются при сборке (`applyUxplayPatches`).
- `./gradlew testDebugUnitTest assembleDebug`
- Ветки `stage-N` с draft PR, CI должен быть зелёным.
